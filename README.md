# Vite+ Monorepo Starter

A starter for creating a Vite+ monorepo.

## Development

- Check everything is ready:

```bash
vp run ready
```

- Run the tests:

```bash
vp run -r test
```

- Build the monorepo:

```bash
vp run scripts -- build
```

- Lint the monorepo:

```bash
vp run scripts -- lint
vp run scripts -- lint --fix
```

- Run the development server:

```bash
vp run scripts -- dev
```
